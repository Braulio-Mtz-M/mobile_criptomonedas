# Aplicación móvil de criptomonedas

## Descripción
Proyecto móvil desarrollado con React Native y Expo.

## Tecnologías utilizadas
- React Native
- Expo
- JavaScript
- TypeScript

## Instalación
1. Instalar las dependencias:

   `npm install`

2. Iniciar el proyecto:

   `npx expo start`

## Desarrollo
El proyecto se utilizará para desarrollar una aplicación móvil relacionada con criptomonedas.
